A custom 3D app inside the gallery

Cartier's product gallery has one slide that loads an iframe from its own subdomain. Behind it is a bespoke application the brand has run since 2021.

A WebGL engine; the app is a "CartierConfigurator" project built in the PlayCanvas editor.

Models

Case, frame, glass, caseback, bracelet and engraving load separately, with diffuse, normal and gloss/metal/AO maps and tiled brushed-steel textures.

One config file maps every reference to its parts and materials, plus prefiltered studio light maps.

Page

Aldaham 3D script

Adds the 3D slide to the gallery with the matched studio lighting, view buttons, AR on phones, a QR code on desktop and live time on watches.

Salla's reference theme already shows 3D models, but with default lighting, no AR, and a viewer version that changes without notice. Matching the photos needs studio lighting set per product family, so the script takes over that slide, or adds it when the theme does not draw one.
  • No per-product code. Any product with a model attached through Salla's app gets the right look for its category automatically.
  • Safe to test on the live store. In test mode the viewer only appears for staff who open a product with ?3d=1.
  • Measured. It sends 3D opens, interactions and AR launches to Google Tag Manager, so conversion can be compared.
  • Installed once. Through the theme's custom JavaScript (Pro or Special plan), or as a private Salla app snippet that survives a theme change.

The real cost is the models

Frank Rosha is Aldaham's own brand, so the factory almost certainly holds the CAD files: jewellery is designed in CAD for casting, and the watch's shop images look like computer renders. Converting those files is the cheapest and most accurate route.

Hosting stays near zero: 300 products at about 4 MB is 1.2 GB, inside Cloudflare R2's free 10 GB, and R2 does not charge for traffic.

Scale

  1. Ask Frank Rosha's suppliers for CAD files of the range.

  4. Consider wrist and finger try-on (Perfect Corp, Banuba) once models exist.
Open points To settle before the pilot

What we need from Aldaham

  • Theme behaviour. Aldaham's theme is a Selia Tech version of Salla's reference theme. Whether it still draws 3D slides is confirmed with one test product; the script works either way.
  • Salla plan and access. Custom JavaScript needs the Pro or Special plan and Store Design permission. A private app snippet is the alternative.
  • Source files. CAD or render scenes from the Frank Rosha suppliers cut cost and make the models exact. Without them, cost and turnaround rise two to four times.
  • AR on iPhone is simpler. Apple's AR view drops glass refraction, brushed-steel direction and diamond fire. The page viewer keeps them.
  • Gallery slot. A 3D model uses one of a product's 10 image slots in Salla.
